JUMPER AI LAB — BẢN WEB VERCEL

Đọc README.md để xem hướng dẫn triển khai đầy đủ bằng tiếng Việt.
Tóm tắt: tạo project Supabase -> chạy schema.sql -> tạo tài khoản quản lý trong Supabase Auth -> đặt role admin bằng SQL -> upload source lên GitHub Private -> import vào Vercel -> thêm 4 biến môi trường -> deploy.

Không gửi SUPABASE_SERVICE_ROLE_KEY cho ai và không commit khóa này lên GitHub.
Bản này dùng Supabase để lưu tài khoản/nhiệm vụ bền vững, không lưu trong RAM của Vercel.
